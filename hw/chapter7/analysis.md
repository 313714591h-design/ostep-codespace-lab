- 预测
当所有工作长度相同时，SJF和FIFO的周转时间相同
- 理由
```

因此SFJ和FIFO都会按照A-B-C的顺序进行
A的周转时间200；B的周转时间400；C的周转时间600
平均周转时间是400：（200+400+600）/3=400。
当工作长度相同时，SJF和FIFO的周转时间相同
```

# Q6
- 预测
随着工作长度增加，SJF的响应时间也会增加
- 理由
```
1.当ABC按照顺序到达，并且使用SJF,SJF先完成短的工作，后面工作才可以开始，前面工作时间越长，后面响应时间越长
假如A=100；B=200；C=300
A先运行，A的响应时间为0，B要等A完成，所以B的响应时间为100，C要等A和B都完成，所以C=100+200=300
2.当A=200 B=400 C=600
A先运行，响应时间为0，B要等A完成 B的响应时间为200， C要等B和A完成，C的响应时间为200+400=600
当前面工作越长，后面的工作需要等待时间就越长，所以随着工作长度增加，SJF的响应时间也会增加。
```

# Q7
- 预测
随着时间片增加，RR的最坏响应时间也会增加。
- 理由
```
RR会让每个工作轮流运行一个时间片。
假设有N个工作，并且他们都在时间0到达。
如果时间片是q，那么第一个响应时间是0
第二个工作需要等第一个工作运行一个时间片是q
第三个需要等前两个工作运行2q
所以最后一个工作需要等前面的N-1个工作。
最坏的响应时间：(N-1)*q
如果有3个工作
时间片q=1；最坏响应时间=（3-1）*1=2
时间片q=2；最坏响应时间=（3-1）*2=4
时间片q=10；最坏响应时间=（3-1）*10=20
所以，时间片越大，最坏情况最后一个工作需要等待的时间越长。
公式：最坏的响应时间=（N-1）*q
每个时间片的长度是q
所以最后一个工作：
等待的时间片数量*每个时间片的长度
（N-1）*q
```
- 验证
- 分析
